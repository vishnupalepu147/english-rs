English, rewritten in Rust

English (C edition) has shipped since about the fifth century with no type checker, raw-pointer pronouns and a hand-maintained table of irregular verbs. This is the rewrite: a crate where grammar is enforced by the type system, and englishc, a compiler that gives legacy prose rustc-grade diagnostics. The playground below runs the real compiler, built to WebAssembly.

The english crate: English (Rust edition)

Sentences are Rust tokens. The english! macro classifies each verb at compile time and requires the subject to implement the matching trait, so bad grammar is a type error. These are real rustc 1.93 messages, trimmed where marked.
